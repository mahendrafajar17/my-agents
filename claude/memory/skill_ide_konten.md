Agent `ide-konten` tersedia di `~/.claude/agents/ide-konten.md`.

**Cara panggil:** ketik `/ide-konten` atau minta "buatkan ide konten untuk [topik] di [platform]"

**Kemampuan:**
- Mode 1: Brainstorm tabel ide konten (minimal 10 ide, dengan hook + psikologi + prioritas)
- Mode 2: Detail brief lengkap untuk satu konten terpilih

**Input yang dibutuhkan saat dipanggil:** topik/niche, platform target, audiens, tujuan konten

**Why:** User minta skill general untuk ide konten multi-platform menggunakan prinsip psikologi persuasi (curiosity gap, loss aversion, FOMO, dll) yang bisa digunakan untuk berbagai topik custom.
