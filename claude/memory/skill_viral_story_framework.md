Agent `viral-story-framework` tersedia di `~/.claude/agents/viral-story-framework.md`, dengan wrapper command di `~/.claude/commands/viral-story-framework.md`.

**Cara panggil:** ketik `/viral-story-framework` atau minta "buatkan caption storytelling dari kejadian ini: [ceritakan kejadian nyata]"

**Untuk:** satu post/video tunggal, cerita personal berbasis kejadian nyata (bukan berseri). Formula 5-beat: hook pembuka (pelanggaran ekspektasi) → konteks/stakes → detail konkret+dialog asli → micro-aksi baik → ending terbuka.

**Guardrail penting:** harus based on kejadian nyata (bukan karangan total), suara otentik, ada kontras dengan narasi dominan yang lagi beredar, tanpa CTA jualan eksplisit.

**Dibedakan dari:** [[skill-serial-hook-framework]] — itu untuk konten berseri/multi-part, ini untuk satu post tuntas.

**Why:** Disusun dari analisis kenapa satu video TikTok kedai kopi ("owner tutup kedai demi karyawan interview") FYP — pola moral elevation + violation of expectation + parasocial bonding.
